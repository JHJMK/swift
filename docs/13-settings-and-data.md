# 设置与数据

[返回教程目录](README.md) · [返回项目主页](../README.md)

本章说明设置页的每个区域、文档在磁盘上的实际结构、配置和日志的位置，以及备份、迁移和隐私相关的注意事项。

## 1. 打开设置

点击侧栏「设置」，或按 `⌘,`（Windows/Linux 为 `Ctrl+,`）。

设置窗口包括：

1. **文档目录**：当前路径、更改并迁移、在 Finder 中打开。
2. **文档显示**：新文档默认的行距和字号；单篇文档可以在页面设置中覆盖。
3. **远端同步**：S3 / NFS / SMB 配置和状态。
4. **诊断日志**：日志目录、保留规则、导出最近三天日志。
5. **当前内容**：知识库和文档数量。
6. **关于**：版本和运行环境。

底部的「完成」会：

- 校验并保存远端同步设置；
- 关闭设置窗口；
- 如果同步已启用，启动或重启同步任务。

如果同步设置不合法，语燕会显示错误，窗口保持打开，不会保存一份无法使用的配置。

## 2. 文档目录

「文档目录」是全部知识库的根文件夹。设置中显示完整路径，并提供：

- **更改目录并迁移…**：选择新文件夹，把当前目录中的全部内容移动过去；
- **在 Finder 中打开**（Windows/Linux 为文件管理器）：打开当前文档目录。

### 2.1 更改目录并迁移

迁移步骤：

1. 点击「更改目录并迁移…」；
2. 选择一个**空文件夹**；
3. 确认迁移；
4. 语燕停止同步，移动当前目录中的全部内容；
5. 更新配置，重新启动同步（如果已启用）。

限制：

- 目标目录必须为空；
- 新目录不能位于当前目录内部；
- 迁移的是当前文档目录中的所有顶层内容，包括知识库和 `.swift/`；
- 迁移期间同步会停止，避免把“移动到一半”的状态上传；
- 迁移失败时可能已经移动了部分文件；语燕会显示错误，请根据错误检查新旧目录，不要在新旧目录同时继续写作；
- 外部知识库不受影响，它们仍在原来的位置。

> **注意**：迁移会真正移动文件，不是复制。迁移前建议先做一份备份，尤其是文档量很大时。

### 2.2 文档显示默认值

设置页的「文档显示」决定新文档的默认行距和字号：

- **行间距**：紧凑（1.5）、标准（1.75）、宽松（2）；
- **默认字体大小**：14、15、16、18、20。

没有单独设置过的文档会实时跟随这里的值；在文档的「页面设置…」里选过值的文档会保留自己的设置，不受影响。要恢复跟随全局，在页面设置中点「恢复为全局默认」。详见[编辑文档](05-editing.md#10-页面设置)。

### 2.3 第一次选择目录

如果还没有文档目录，会先显示欢迎页；选择目录后才进入工作台和设置。选择目录的流程见[安装与首次启动](01-getting-started.md)。选择已有内容的文件夹时：

- 顶层的每个文件夹会被当作一个知识库；
- 根部的 `.md` 文件不会显示在树中；
- 语燕会创建或复用 `.swift/` 元数据。

## 3. 文档在磁盘上的结构

```text
文档目录/
├── 工作笔记/                     ← 知识库
│   ├── 项目计划.md               ← 文档
│   ├── 项目计划/                 ← 该文档的子文档
│   │   ├── 需求.md
│   │   └── 排期.md
│   ├── 会议/                     ← 目录
│   │   └── 周会.md
│   └── .assets/                  ← 图片和附件
│       ├── 1700000000000-架构图.png
│       └── 1700000000001-需求.pdf
├── 学习资料/                     ← 另一个知识库
│   └── ...
└── .swift/                       ← 语燕元数据
    ├── order.json
    ├── recent.json
    ├── external.json
    ├── note.json
    ├── note-assets/
    ├── trash/
    │   └── <条目ID>/
    │       ├── meta.json
    │       ├── data
    │       └── children
    └── sync-state.json
```

### 3.1 各部分的含义

| 路径 | 内容 | 能否手动修改 |
| --- | --- | --- |
| 顶层文件夹 | 知识库 | 可以，但建议通过语燕操作 |
| `.md` 文件 | 文档 | 可以用其他 Markdown 工具编辑 |
| 同名文件夹 | 文档的子文档 / 子目录 | 建议通过语燕操作 |
| `.assets/` | 图片、附件、Mermaid 缓存 | 不要单独移动或重命名 |
| `.swift/` | 排序、最近打开、外部引用、小记、回收站、同步清单 | 不要手动修改或删除 |

### 3.2 `.swift` 中的文件

| 文件 | 作用 |
| --- | --- |
| `order.json` | 每个目录下条目的显示顺序 |
| `recent.json` | 最近打开的 20 篇文档 |
| `external.json` | 外部知识库的名称和路径 |
| `note.json` | 小记的标题和正文 |
| `note-assets/` | 小记的图片和附件 |
| `trash/` | 回收站条目 |
| `sync-state.json` | 远端同步清单（启用同步后出现） |

删除 `.swift/` 会丢失回收站、小记、排序、最近打开和同步状态；文档本身可能仍在，但语燕会把它当作一个新的工作区。除非你清楚后果，否则不要删除。

### 3.3 隐藏文件

`.assets/` 和 `.swift/` 以 `.` 开头，通常不在 Finder / 资源管理器中直接显示。macOS 可按 `⇧⌘.` 显示隐藏文件。不要为了让它们“看起来干净”而删除或重命名。

## 4. 配置文件和日志的位置

这些文件不在文档目录中，因此移动文档目录时不会自动跟着走。

### 4.1 配置文件

| 系统 | 路径 |
| --- | --- |
| macOS | `~/Library/Application Support/Swift/config.json` |
| Windows | `%AppData%\Swift\config.json` |
| Linux | `$XDG_CONFIG_HOME/Swift/config.json`（通常 `~/.config/Swift/config.json`） |

配置包括：

- 文档目录路径；
- 文件树、大纲宽度；
- 全局文档显示默认值；
- 每篇文档覆盖的页面设置；
- 远端同步设置和凭据。

窗口大小等状态由 MyGo 在配置目录中单独保存，不在 `config.json` 里。

配置文件权限为当前用户可读写；其中可能包含 S3 密钥，**不要提交到版本控制仓库、同步到公共云盘或发给他人**。

### 4.2 日志

| 系统 | 路径 |
| --- | --- |
| macOS | `~/Library/Application Support/Swift/logs/` |
| Windows | `%AppData%\Swift\logs\` |
| Linux | `$XDG_CONFIG_HOME/Swift/logs/`（通常 `~/.config/Swift/logs/`） |

- 文件名：`swift-YYYY-MM-DD.log`；
- 只保留今天和前两个自然日，共 3 天；
- 内容包括 Go 主程序、MyGo 和 Web 编辑器的警告/错误；
- 常见的 `access_key`、`secret_key`、`token`、`Authorization` 等字段会被脱敏；
- 不主动记录文档正文；
- 只保存在本机，不会自动上传。

设置页的「诊断日志」区域可以查看目录，并「导出最近 3 天日志…」为 ZIP。

## 5. 诊断日志与排错

遇到问题时：

1. 打开设置 > 诊断日志；
2. 点击「导出最近 3 天日志…」；
3. 选择保存位置；
4. 把 ZIP 提供给开发者，并说明：
   - 你的操作系统和语燕版本；
   - 复现步骤；
   - 是否使用了同步、外部知识库、Lakebook 导入；
   - 错误提示的原文。

日志可能包含文档路径和文件名，但不会主动包含正文。发送前可以自行查看 ZIP 内容。

## 6. 当前内容和关于

- **当前内容**：显示知识库和文档数量，帮助你确认数据是否完整。
- **关于**：显示语燕版本、运行环境（纯 Go / MyGo 原生界面）等信息。

关于页的版本号来自项目根目录的 `mygo.json`：`mygo build` / `mygo dev` 会把它写入应用元数据；直接用 `go run .` 运行时从工作目录或其上级目录读取 `mygo.json`，找不到时显示「开发版」。教程中的截图可能来自不同开发版本。

## 7. 与 Finder 和其他编辑器协作

语燕会监视当前打开的知识库文件夹：

- 在 Finder 或其他编辑器中新建、重命名、移动、删除 Markdown 文件，语燕会刷新目录树；
- 修改正在打开的文档，语燕会在没有本地未保存修改时自动重新载入；
- 如果本地有未保存修改，语燕会保留本地内容，并提示磁盘文件已更新；
- 文件在外部被删除时，未保存的内容会尽量保留在编辑器中，方便另存；
- 文件被外部移动或重命名时，语燕会尽量跟随，并更新当前文档路径。

建议：

- 不要在语燕打开文档时，用其他工具同时写入同一篇文档；
- 用其他工具编辑时，先确认语燕状态为「已保存」；
- 外部工具修改后，等语燕提示「文档已从磁盘更新」再继续；
- 如果在外部删除了文件，回收站不会收到它；需要从备份恢复。

## 8. 备份、迁移和恢复

### 8.1 备份整个文档目录

最简单的方式：

1. 退出语燕（或至少停止编辑并确认已保存）；
2. 复制整个文档目录到备份位置；
3. 如需保留设置和同步配置，再复制 `Swift/config.json`。

复制整个目录会包含：

- 全部知识库和文档；
- 图片、附件；
- `.swift/` 中的回收站、小记、排序和最近打开；
- 同步清单（可选）。

### 8.2 只备份知识库

- 在语燕中导出知识库 ZIP；
- 或直接复制某个知识库文件夹（包括 `.assets/`）。

这种方式不包含回收站、小记和设置；适合共享或归档。

### 8.3 换电脑

1. 在新电脑安装语燕；
2. 复制整个文档目录到新电脑；
3. 首次启动时选择这个目录；
4. 如果需要同步，重新填写远端配置（或复制 `config.json`，但注意路径和密钥）；
5. 检查外部知识库路径是否仍然有效。

### 8.4 从备份恢复

- 把备份的文档目录放回原路径，或放到新路径后在设置中选择；
- 如果配置文件还指向旧路径，重新选择目录；
- 如果只恢复了知识库文件夹，`.swift` 中的回收站和小记不会恢复；
- 恢复后先搜索几篇文档并打开图片，确认资源完整。

### 8.5 版本历史

语燕没有内置的文档版本历史。需要版本控制时：

- 使用版本控制工具管理文档目录（注意忽略 `.swift/` 和 `.assets/` 是否要纳入）；
- 使用远端存储的版本控制（S3 Versioning）；
- 定期导出知识库 ZIP 或复制整个目录。

## 9. 隐私和安全

- 语燕是本地优先应用，不包含账号系统、遥测或统计上报；
- 文档默认只保存在本机；
- 只有以下操作会联网：
  - 远端同步；
  - 导入 Lakebook 时下载图片；
  - 打开外部链接；
  - 文档中引用的网络图片加载；
- 诊断日志只在本机，保留 3 天，并对常见凭据字段脱敏；
- S3 密钥以明文保存在本机配置文件中，依赖系统账户和文件权限保护；
- 语燕不提供应用级密码、文档加密或生物识别锁；
- 需要更强保护时，请使用系统磁盘加密（FileVault、BitLocker、LUKS）、受保护的账户和最小权限的云密钥；
- 外部知识库是可读写的活引用，语燕会直接读写原文件夹；请确认来源可信，并在编辑前做好原目录的备份。

## 10. 重置和清理

- **重新选择文档目录**：在设置中更改并迁移，或删除配置中的 workspace 后重新启动；
- **清空回收站**：释放被彻底删除内容占用的空间；
- **清理日志**：可以删除 `Swift/logs/` 中的旧文件；语燕也会自动清理 3 天前的日志；
- **重置界面宽度**：删除或修改配置中的 `fileTreeWidth`、`outlineWidth`，重新启动；
- **不要**直接删除 `.swift/` 来“重置”，除非你接受回收站、小记、排序和同步状态丢失。

## 11. 常见问题

**Q：配置文件可以跟着文档目录一起移动吗？**

不建议直接复制。配置中包含绝对路径和同步凭据，换路径后需要重新选择或修改。文档目录本身可以整体移动。

**Q：为什么设置里显示的知识库数量和侧栏不一致？**

工作台统计包含外部知识库；侧栏也列出外部知识库。若某个外部路径不可用，它不会显示。

**Q：删除配置会删除文档吗？**

不会。配置只保存设置；文档在文档目录中。删除配置后，下次启动需要重新选择目录。

**Q：日志会包含我的笔记内容吗？**

不会主动记录正文；但错误信息可能包含文件路径或文件名。发送前可以检查 ZIP 内容。

**Q：如何只清空回收站，不删文档？**

在回收站中「清空回收站」。文档目录中的正常文档不受影响。

**Q：如何把文档目录放到移动硬盘？**

把整个目录复制到移动硬盘，然后在设置中选择新位置（或迁移）。使用前确保硬盘已挂载；否则语燕会显示欢迎页或无法打开文档。
