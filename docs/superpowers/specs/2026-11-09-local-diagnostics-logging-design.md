# 本地诊断日志设计

## 目标

语燕在本机持续记录 Go、MyGo 和 Web 编辑器产生的诊断信息，仅保留最近三天，并允许用户从设置中把这段时间的日志导出为 ZIP，交给开发者排查问题。

## 日志范围

- Go 主程序和 MyGo 通过标准库 `log` 输出的日志。
- Web 编辑器捕获的 `console.warn`、`console.error`、未捕获异常和未处理的 Promise 异常。
- 不记录普通 `console.log`，避免日志量失控。
- 不主动记录文档正文；对常见凭据字段和鉴权头做脱敏。

## 存储与保留

日志保存在 `<系统配置目录>/Swift/logs/`，文件名格式为 `swift-YYYY-MM-DD.log`。日志目录权限为 `0700`，日志文件权限为 `0600`。

“最近三天”指今天和前两个自然日。应用启动、跨天写入以及导出前都会清理更早的日志文件。日志按日期追加写入；跨天时自动切换到新文件。

## 写入流程

Go 侧通过一个并发安全的日志写入器接管标准库日志输出，同时保留终端输出。写入器按当前日期延迟打开或轮转文件，因此现有 Go/MyGo 日志调用不需要逐个修改。

Web 编辑器通过现有 MyGo bridge 调用 Go 侧的日志方法。前端在启动时安装错误监听器，并在写入前压平消息和堆栈，避免向前端回传异常。

如果日志初始化或写入失败，应用继续运行，并在终端报告错误。导出失败时在现有设置页或错误提示区域显示原因。

## 设置与导出

设置页在“远端同步”和“当前内容”之间增加“诊断日志”区域，显示日志目录、三天保留规则和“导出最近 3 天日志…”按钮。

点击导出后打开系统保存对话框，默认文件名为 `语燕日志-YYYY-MM-DD.zip`。ZIP 只包含今天和前两个自然日对应的现有日志文件。

## 测试

- 日志写入当天的日期文件。
- 跨天后切换到新文件。
- 清理今天以前超过两天的日志。
- ZIP 只包含最近三天的日志。
- 前端警告和错误通过 bridge 写入日志。
- 设置页显示诊断日志说明和导出入口。

最终运行 `go test ./...`、`go vet ./...`、`go tool mygo vet .`、Web 编辑器检查和构建，并启动应用截图检查设置页。
