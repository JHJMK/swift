# 可调整侧栏宽度设计

## 目标

文件树和文档大纲各增加一条可拖动的竖向分隔线，让用户调整侧栏与正文的宽度比例。

## 交互

- 文件树默认 `220px`，最小 `180px`，最大 `360px`。
- 文档大纲默认 `240px`，最小 `180px`，最大 `420px`。
- 分隔线有约 `7px` 的拖动热区，悬停时显示左右拉伸光标，拖动时高亮。
- 宽度在拖动结束后保存到 `config.json`，重新启动应用后继续使用。
- 拖动只改变对应侧栏的宽度，不移动大纲的位置，也不改变折叠行为。

## 实现

### 文件树

知识库文件树在原生 mygo 布局中绘制。宽度从配置读取，并在文件树右边界放置一个绝对定位的分隔条。分隔条用 `Dragged` 接收水平位移，将文件树宽度限制在边界内并触发重绘；拖动结束时保存配置。

### 文档大纲

文档大纲在 Web 编辑器中绘制。增加一个绝对定位的拖动热区，使用 Pointer Events 修改大纲的 CSS 宽度，并按同样的上下限约束。Web 页面通过现有的 mygo bridge 在拖动结束后把最终宽度写回 Go 配置。

## 验证

- 原生 UI 测试覆盖拖动文件树分隔条、最小宽度和最大宽度。
- Go 测试覆盖大纲宽度边界与配置保存。
- `go test ./...`、`go vet ./...`、Web 编辑器 `npm run check` 和 `npm run build` 通过。
- 启动开发版应用，实际检查两条分隔线的悬停光标、拖动结果和界面布局。
