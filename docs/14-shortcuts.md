# 快捷键与技巧

[返回教程目录](README.md) · [返回项目主页](../README.md)

本章汇总常用快捷键、斜杠命令和鼠标操作，以及一些能明显提高效率的小技巧。

> `⌘` 表示 macOS 的 Command 键。Windows 和 Linux 上，绝大多数快捷键使用 `Ctrl`；`⇧` 表示 Shift。菜单中显示的快捷键由系统决定，以实际界面为准。

## 1. 全局快捷键

| 快捷键 | 作用 | 说明 |
| --- | --- | --- |
| `⌘N` | 新建文档 | 选中目录时在目录内创建；选中文档时在它所在目录（同级）创建；没有选中项时放在第一个知识库 |
| `⌘K` | 搜索 | 打开全局搜索窗口 |
| `⌘,` | 设置 | 打开设置 |
| `⌘F` | 查找 | 在当前文档中查找/替换 |
| `⌘/` | 插入块 | 打开块类型菜单；Web 编辑器中相当于输入 `/` |
| `⇧⌘A` | 插入附件 | 选择一个文件插入当前文档 |
| `⌘Z` | 撤销 | 编辑器内生效 |
| `⇧⌘Z` | 重做 | 编辑器内生效 |
| `⌘X` / `⌘C` / `⌘V` | 剪切 / 复制 / 粘贴 | 文本字段和编辑器使用系统行为 |
| `⌘A` | 全选 | 当前输入区域；光标在代码块中时只选中代码块内的内容，在外才是整篇文档 |
| `⌘W` | 关闭窗口 | 系统行为 |
| `⌘Q` | 退出语燕 | 系统行为；退出前会尽量保存 |

> **注意**：语燕没有「保存」快捷键，因为文档会自动保存。`⌘S` 不会触发额外操作；确认状态为「已保存」即可。

### 1.1 菜单栏

| 菜单 | 项目 |
| --- | --- |
| 文件 | 新建文档、新建知识库、复制导入知识库…、引用外部知识库…、新建目录、搜索、设置… |
| 编辑 | 撤销、重做、剪切、复制、粘贴、粘贴并匹配样式、全选、查找 |
| 插入 | 插入块…、附件…、图片… |
| 格式 | 系统文本格式菜单 |
| 窗口 | 系统窗口菜单 |

「编辑 > 粘贴」只在编辑器获得焦点时可用；当焦点在输入框中时，`⌘V` 仍走系统文本粘贴。

## 2. 编辑器快捷键

以下快捷键适用于默认的 Web 编辑器：

| 快捷键 | 作用 |
| --- | --- |
| `⌘B` | 加粗 |
| `⌘I` | 斜体 |
| `⇧⌘X` | 删除线 |
| `⌘E` | 行内代码 |
| `⇧⌘K` | 插入/编辑链接 |
| `⌘1`–`⌘6` | 设置为标题 1–6 |
| `⌘0` | 恢复为正文 |

### 2.1 在标题中

| 按键 | 作用 |
| --- | --- |
| `Enter` | 提交标题并回到正文 |
| `Esc` | 放弃本次标题修改 |
| `↓` | 从标题进入正文 |

### 2.2 斜杠菜单

| 按键 | 作用 |
| --- | --- |
| `/` | 在行首或空格后打开块菜单 |
| 输入文字 | 过滤命令 |
| `↑` / `↓` | 选择命令 |
| `Enter` | 执行 |
| `Esc` | 关闭 |

### 2.3 代码块

Web 编辑器把代码块当作普通 Markdown 围栏编辑：

- 光标可以用方向键移入、移出；
- `⌘A`（Windows/Linux 为 `Ctrl+A`）只选中当前代码块内的内容；光标在代码块外时才是全选整篇文档；
- `Enter` 在代码块中换行；
- 代码块内不会触发斜杠菜单；
- 右上角有复制按钮；
- 语言标注写在开头的反引号后，例如 ` ```go `。

> **提示**：如果系统回退到原生编辑器，代码块的编辑行为略有不同，界面会提示「Enter 换行 · ⌘Enter 退出代码块」。

| `/标题 1`、`/标题 2`、`/标题 3` | 插入对应标题 |
| `/无序列表` | 圆点列表 |
| `/有序列表` | 编号列表 |
| `/任务列表` | 可勾选列表 |
| `/引用` | 引用块 |
| `/代码块` | 围栏代码块 |

## 5. 布局技巧

- **先收起侧栏，再收起目录树**：获得最大写作宽度；左边缘的「展开目录」按钮可以恢复。
- **宽窄模式**：大屏看代码/表格用宽模式，长文阅读用窄模式。
- **大纲**：长文档先开大纲，点击标题快速跳转；大纲宽度可拖动。
- **页面设置**：在设置里调全局默认行距和字号，单篇文档可以覆盖；都不影响 Markdown。
- **预览模式**：分享或检查排版前切换，避免误改。

## 6. 整理技巧

- **先选中目标再 `⌘N`**：文档会直接创建在选中的目录或文档下，省去位置选择器。
- **拖动排序**：知识库、目录和文档都可以上下拖动调整顺序；拖到行的上下边缘是同级排序，拖到行中间是放进目录或变成子文档。
- **复制全部子资源**：复制项目目录时，子文档和图片一起带走。
- **移出目录**：放错层级时上移一级，不必删除重建。
- **外部知识库**：只在语燕中查看已有目录，避免复制和同步；要编辑时再复制导入。
- **命名稳定**：知识库和目录名就是文件夹名，避免频繁改名；文档标题可以随时改。

## 7. 写作技巧

- **先写后排版**：用 `/` 快速插入块，写完再统一调整标题层级。
- **标题不要重复**：页面顶部已有标题，正文从 `##` 开始通常更清爽。
- **任务列表**：会议待办、项目清单用 `- [ ]`，点击即可勾选。
- **代码块写语言名**：` ```go `、` ```sql ` 会获得语法高亮和语言标签。
- **Mermaid**：流程图、时序图、甘特图都可以直接写在文档里，点击图表可改源码。
- **图片和附件**：让语燕复制到 `.assets/`，不要引用桌面临时文件。
- **查找/替换**：`⌘F` 是当前文档；跨文档找内容用 `⌘K`。

## 8. 检索技巧

- 记得标题时，直接搜标题词；
- 只记得大致范围时，先限定知识库，再扩大；
- 中文搜索用短语，不要输入整句；
- 结果最多 50 条，关键词越具体越好；
- 找当前文档中的词用 `⌘F`，不要用全局搜索。

## 9. 备份技巧

- **Markdown 导出**：单篇归档，保留图片和附件；
- **知识库 ZIP**：整库归档；
- **远端同步**：持续镜像到 S3/NFS/SMB，但注意它是单向的；
- **额外备份**：重要内容再复制一份到其他磁盘或开启 S3 版本控制；
- **定期检查恢复**：备份只有在能恢复时才有价值，偶尔解压一个 ZIP 或还原一篇文档试试。

## 10. 平台差异

| 功能 | macOS | Windows / Linux |
| --- | --- | --- |
| 主修饰键 | `⌘` | `Ctrl` |
| 设置 | `⌘,` | `Ctrl+,` |
| 在文件管理器中显示 | Finder | 资源管理器 / 文件管理器 |
| 显示隐藏文件 | `⇧⌘.` | 资源管理器「查看 > 隐藏的项目」 |
| 关闭窗口 | `⌘W` | `Alt+F4` / 窗口关闭按钮 |

界面中的部分提示固定显示 `⌘`，在 Windows/Linux 上请按 `Ctrl` 理解。
