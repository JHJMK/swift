## 常用入口速查

- **工作台**：侧栏「工作台」。新建文档、新建知识库、搜索、导入，以及全部知识库的文章、字数和活跃度统计。
- **小记**：侧栏「小记」。不归属任何知识库的速记，之后可以「保存到」知识库。
- **搜索**：侧栏搜索框或 `⌘K`。搜索标题和正文，可限定知识库或当前资源。
- **回收站**：侧栏「回收站」。删除的内容先放在这里，可还原或彻底删除。
- **设置**：侧栏「设置」或 `⌘,`。文档目录、远端同步、诊断日志、版本与 GitHub 仓库地址。
- **插入块**：编辑器里输入 `/`，或使用菜单「插入 > 插入块…」（`⌘/`）。

## 术语

| 术语 | 含义 |
| --- | --- |
| 文档目录 | 语燕保存全部知识库的根文件夹，在首次启动或设置中选择。 |
| 知识库 | 文档目录下的一个顶层文件夹，是内容组织的第一层。 |
| 目录 / 分组 | 知识库里的文件夹。界面在不同位置分别称「目录」和「分组」，本质相同。 |
| 文档 | 一个 `.md` 文件，也就是一篇笔记。 |
| 子文档 | 挂在某篇文档下面的文档。磁盘上表现为与文档同名的文件夹。 |
| 资源 | 左侧全局侧栏中位于最前面的入口（工作台、小记、回收站、设置）以及知识库中的一项内容。 |
| 小记 | 暂存在知识库之外的速记，保存到知识库后成为正式文档。 |
| 远端同步 | 把本地文档目录单向镜像到 S3、NFS 或 SMB 的备份功能，不是双向协作。 |
| 外部知识库 | 引用文档目录之外的一个文件夹，直接在语燕中读写原文件夹，不复制内容。 |

## 阅读约定

- **菜单路径**写作「文件 > 新建文档」。
- **按钮名称**使用界面上的原文，例如「新建文档」「保存到」「立即同步」。
- **代码和快捷键**使用等宽字体，例如 `⌘K`、`markdown`。
- **提示**和**注意**用引用块标出；两者都不是可跳过的小字，尤其是涉及删除和同步时。
- 本教程以当前默认的 **Web 编辑器**（实时预览）为主。极少数系统缺少 WebView 时，语燕会回退到内置的原生编辑器，部分菜单位置会不同，文中会单独说明。
