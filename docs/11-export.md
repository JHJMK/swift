# 导出

[返回教程目录](README.md) · [返回项目主页](../README.md)

语燕支持四种导出：

| 导出 | 入口 | 结果 |
| --- | --- | --- |
| Markdown（含图片） | 文档页「更多」、文档行「更多操」 | ZIP：Markdown + 图片/附件 |
| PDF | 文档页「更多」、文档行「更多操作」 | A4 PDF |
| Word (.docx) | 文档页「更多」 | Word 文档 |
| 知识库 ZIP | 知识库行「更多」、知识库首页「更多」 | 整个知识库文件夹的 ZIP |

导出会先保存当前文档，不会修改正文或 Markdown 文件。

## 1. 导出 Markdown（含图片）

### 1.1 步骤

1. 打开文档；
2. 点击右上角 `…` > 「导出 Markdown（含图片）」；
3. 选择保存位置和文件名；
4. 语燕生成一个 ZIP。

也可以在某篇文档的目录树行 `…` > 「导出 Markdown（含图片）」；语燕会先打开它，再导出。

### 1.2 ZIP 结构

假设文档标题为「项目计划」：

```text
项目计划.zip
└── 项目计划/
    ├── 项目计划.md
    └── 项目计划.assets/
        ├── 1700000000000-架构图.png
        └── 1700000000001-需求.pdf
```

- Markdown 中的本地图片和附件会被复制到 `<标题>.assets/`；
- 图片/附件链接会被改写为 `标题.assets/文件名`；
- 只包含文档实际引用的资源；
- 重复文件名会自动加编号；
- 标题中的空格会替换为 `-`；
- 非法文件名字符会被替换；
- 标题为空时使用「未命名」；
- 扩展名不是 `.zip` 时会自动补上。

### 1.3 适合的场景

- 长期归档；
- 迁移到其他 Markdown 工具；
- 发给可以打开 Markdown 和图片的人；
- 作为比 PDF/Word 更保真的副本。

## 2. 导出 PDF

### 2.1 步骤

1. 打开文档；
2. 点击右上角 `…` > 「导出为 PDF」；
3. 选择保存位置和文件名；
4. 语燕在后台生成 A4 PDF。

也可以从文档行的 `…` 菜单导出 PDF。

### 2.2 特点

- A4 页面，带页边距；
- 图片会嵌入 PDF，不依赖原文件；
- 适合阅读、打印和分享；
- 生成过程使用隐藏页面打印，不会弹出浏览器窗口；
- 通常几秒内完成；超过 20 秒会提示「PDF 生成超时」；
- 导出失败会显示错误横幅。

### 2.3 保真度

PDF 由 Markdown 转换后的 HTML 打印生成，以下内容可能与编辑器显示不同：

- 表格可能以制表符分隔的文本呈现，而不是带边框的表格；
- 复杂嵌套列表；
- Mermaid 等嵌入内容通常以代码块文本出现，而不是渲染后的图形；
- 字体和行距；
- 分页位置；
- 很长的代码行。

需要严格保真时，请使用 Markdown 导出或保留原始应用中的排版。

## 3. 导出 Word（.docx）

### 3.1 步骤

1. 打开文档；
2. 点击右上角 `…` > 「Word (.docx)」；
3. 选择保存位置和文件名；
4. 语燕生成 `.docx`。

### 3.2 支持的内容

- 标题 1–6；
- 普通段落；
- 无序列表、有序列表、任务列表；
- 引用；
- 代码块（等宽字体和浅色底纹）；
- 加粗、斜体、下划线、删除线、行内代码；
- 链接；
- 本地图片（支持的格式）；
- 表格通常以文本形式保留，不保证生成 Word 表格。

### 3.3 保真度

Word 导出面向“可编辑的分享稿”，不保证与页面像素级一致：

- 复杂表格、合并单元格、嵌入图表可能丢失结构；表格通常不会还原为 Word 表格；
- 自定义字体、颜色、缩进可能与编辑器不同；
- Mermaid 图表通常以代码块文本导出，不会成为可编辑图形；
- 页眉页脚、页码不会自动生成。

需要完整内容时，优先导出 Markdown。

## 4. 导出整个知识库

### 4.1 步骤

1. 在侧栏知识库行点击 `…` > 「导出」；
2. 或打开知识库首页，点击「更多」> 「导出」；
3. 选择保存位置；
4. 语燕把整个知识库文件夹打包为 ZIP。

### 4.2 包含什么

- 全部 `.md` 文档；
- 全部目录和子文档文件夹；
- `.assets/` 中的图片和附件；
- 知识库中的其他普通文件；
- 不包含 `.DS_Store`；
- 不包含文档目录根部的 `.swift/`（它不在知识库内部）。

ZIP 顶层是知识库文件夹名，解压后即可用 Markdown 工具打开。

### 4.3 限制

- 不能把 ZIP 保存到知识库自己的文件夹内部；
- 不能只导出某个目录（当前版本只支持整库导出）；
- 外部知识库也可以导出；导出的是它原文件夹的当前内容；
- 导出不会停止远端同步，但不会把导出文件写回知识库（除非你选择的位置在知识库内，语燕会拒绝）。

## 5. 默认位置和文件名

- 默认保存到当前用户的桌面（`Home/Desktop`）。
- 文档导出默认文件名是 `<标题>.zip`、`<标题>.pdf`、`<标题>.docx`。
- 知识库导出默认文件名是 `<知识库名>.zip`。
- 保存对话框中可以修改位置和名称。
- 同名文件是否覆盖由系统保存对话框决定；语燕不会静默覆盖已有文件。

## 6. 选择哪种格式

| 需求 | 推荐 |
| --- | --- |
| 长期归档、再次编辑 | Markdown（含图片） |
| 阅读、打印、发给普通人 | PDF |
| 在 Word 中继续修改 | Word (.docx) |
| 备份或迁移整个知识库 | 知识库 ZIP |
| 需要完整表格/代码/链接 | Markdown |
| 需要保留附件 | Markdown ZIP 或知识库 ZIP |

## 7. 常见问题

**Q：导出的 Markdown 图片在哪里？**

在 ZIP 中的 `<标题>.assets/` 文件夹里。解压后，Markdown 和 assets 要保持相对位置，否则图片链接会失效。

**Q：导出的 PDF 排版和编辑器不一样？**

PDF 使用打印样式，不是编辑器屏幕样式；复杂表格、Mermaid、字体可能导致差异。需要一致时用 Markdown。

**Q：Word 里的表格为什么不是表格？**

当前转换通常把表格保留为制表符分隔的文本，而不是 Word 表格。需要完整表格时请用 Markdown 导出。

**Q：能批量导出多篇文档吗？**

可以导出整个知识库 ZIP；当前没有“选中多篇导出”的功能。

**Q：导出的文件会同步到远端吗？**

不会。导出文件保存在你选择的位置，不属于知识库内容，除非你手动放回知识库。

**Q：PDF 导出超时怎么办？**

重试；如果文档特别大或图片很多，可以拆分文档，或改用 Markdown 导出。错误信息会保留在界面上。

**Q：导出会修改原文档吗？**

不会。导出前只会保存当前编辑内容；Markdown 文件本身不变。
