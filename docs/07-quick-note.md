# 小记

[返回教程目录](README.md) · [返回项目主页](../README.md)

小记是语燕的“随手记”区域：它不归属任何知识库，适合在整理之前快速记下一段想法、待办、链接或图片，之后再归入正式的知识库。

## 1. 打开小记

点击左侧全局侧栏的「小记」。语燕会打开唯一的一篇小记：

- 顶部状态显示「小记 · 已保存 HH:MM:SS」；
- 页面标题可以直接编辑；
- 正文区域和普通文档一样支持 Markdown、图片、附件、代码块等；
- 顶部右侧只有「保存到」按钮，没有大纲、宽窄模式、预览、更多等文档操作；
- 底部仍然显示词数和字符数。

## 2. 小记的保存

- 小记同样自动保存，不需要点保存。
- 内容保存在文档目录下的 `.swift/note.json` 中，而不是某个知识库里的 `.md` 文件。
- 小记中的图片和附件保存在 `.swift/note-assets/` 中。
- 退出、切换页面或重新打开语燕后，小记内容仍在。
- 小记标题和正文一起保存；标题为空时默认使用「小记」。

> **注意**：小记不属于任何知识库，因此：
>
> - 它不会出现在全局搜索中；
> - 它不参与远端同步；
> - 它不会出现在回收站中；
> - 它不能被单独导出为 Markdown，直到你把它保存到知识库。

## 3. 把小记保存到知识库

点击顶部「保存到」，打开位置选择器：

1. 选择目标知识库、目录或文档；
2. 点击「保存」；
3. 语燕会：
   - 用当前小记标题（为空时用「小记」）创建一篇新文档；
   - 把正文写入这个 `.md` 文件；
   - 把小记中引用的图片和附件复制到目标知识库的 `.assets/`；
   - 改写正文中的资源链接；
   - 清空小记（包括 `note.json` 和不再使用的 `note-assets/`）；
   - 打开刚创建的正式文档。

如果还没有任何知识库，语燕会先创建默认的「我的知识库」，再保存。

选择文档作为目标时，小记会成为这篇文档的子文档，和普通新建文档的规则相同。

### 保存失败时

如果写入失败（例如磁盘已满、目标位置不可写），语燕会显示错误，小记内容仍保留，不会丢失。修正问题后再次「保存到」即可。

## 4. 小记和文档的区别

| 特性 | 小记 | 普通文档 |
| --- | --- | --- |
| 所属位置 | 知识库之外 | 某个知识库中 |
| 存储 | `.swift/note.json` | `.md` 文件 |
| 数量 | 只有一篇 | 任意多篇 |
| 搜索 | 不参与 | 参与 |
| 远端同步 | 不参与 | 参与 |
| 回收站 | 不参与 | 参与 |
| 导出 | 先保存到知识库 | 直接导出 |
| 大纲 / 页面设置 | 不提供 | 提供 |

## 5. 典型用法

### 5.1 稍后整理

开会或阅读时，把想法、链接、截图快速贴进小记；有空时再「保存到」对应的知识库和目录，整理成正式文档。

### 5.2 临时草稿

写一篇长文前，先在小记里列提纲；完成后保存到知识库，继续补充。

### 5.3 跨知识库暂存

当你不确定内容应该归入哪个知识库时，先放进小记；想清楚后再选择位置。

### 5.4 清空小记

小记没有单独的「删除」按钮。如果要丢弃内容：

- 可以全选正文删除，再修改标题，让它成为一篇空白小记；或
- 先保存到知识库，再在知识库中删除那篇文档，让它进入回收站。

后者更安全，因为回收站可以还原。

## 6. 备份与迁移

- 小记保存在 `.swift/note.json`，图片在 `.swift/note-assets/`。复制整个文档目录会一并备份它们。
- 但小记**不会**被远端同步上传，因为同步会跳过 `.swift/`。
- 换电脑时，如果要保留小记，需要复制整个文档目录，而不是只依赖远端同步。
- 保存到知识库后，小记就变成了普通文档，会参与搜索、同步、导出和回收站。

## 7. 小记中的图片和附件

- 粘贴图片、拖入文件、使用工具栏插入，都会进入 `.swift/note-assets/`；
- 保存到知识库时，只迁移正文中实际引用的资源；
- 未被引用的图片和附件会在保存后被清理；
- 小记的资源路径与知识库不同，不要手动复制到别的知识库；用「保存到」让语燕处理。

## 8. 常见问题

**Q：小记会同步到手机或其他电脑吗？**

不会。小记在 `.swift/` 中，远端同步不包含它。保存到知识库后才会同步。

**Q：能同时有多篇小记吗？**

不能。语燕只有一个速记位置。需要多篇时，请保存到知识库后新建下一篇，或直接使用知识库文档。

**Q：小记标题为什么没有出现在搜索里？**

搜索只扫描知识库中的 `.md` 文档。小记保存为正式文档后才会被搜索。

**Q：保存到知识库后，小记还能恢复吗？**

保存会清空小记。原内容已在新文档中；如果需要“撤销”，可以在知识库中删除该文档（进入回收站），但小记本身不会自动恢复。建议保存前确认目标位置。
