# 远端同步

[返回教程目录](README.md) · [返回项目主页](../README.md)

远端同步把本地文档目录**单向镜像**到远端：本地新增或修改的文件会上传，本地删除的文件会从远端删除。它适合把笔记备份到 NAS、对象存储或一台常开的服务器。

> **这不是双向同步。** 语燕不会把远端的改动拉回本地，也不做冲突合并。请不要在多台设备上同时编辑同一个文档目录；详见[第 9 节](#9-安全边界和限制)。

## 1. 同步模型

```text
本地文档目录  ───── 上传新增/修改 ─────▶  远端
     │                                      │
     └──── 删除（彻底删除后）──────────────▶ 删除远端副本

远端不会把改动推回本地。
```

支持的远端：

| 类型 | 说明 | 适合 |
| --- | --- | --- |
| S3 | Amazon S3 或兼容 S3 的对象存储（MinIO、Ceph、部分云厂商） | 异地备份、对象存储 |
| NFS | 已挂载到本机的 NFS 共享文件夹 | 局域网 NAS |
| SMB | 已挂载到本机的 SMB / Windows 共享文件夹 | 局域网 NAS、Windows 共享 |

同步记录保存在文档目录的 `.swift/sync-state.json`，记录每个文件的大小、修改时间和内容哈希，用来判断是否需要上传。

## 2. 打开同步设置

1. 点击侧栏「设置」（或 `⌘,`）；
2. 找到「远端同步」；
3. 打开「启用」；
4. 选择类型；
5. 填写对应参数；
6. 点「完成」保存并启动。

如果同步已经在运行，设置没有变化时点「完成」不会重启任务；设置变化时会等当前这一轮同步结束后再重启。

> **注意**：设置页里的修改只有在点「完成」后才会保存并应用。直接关闭设置窗口不会保存新的同步配置。

## 3. S3 配置

选择「类型：S3」后填写：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| 服务地址 | 留空使用 Amazon S3；自建存储填 Endpoint | `https://s3.example.com`、`https://minio.example.com` |
| 区域 | S3 区域；留空按 `us-east-1` | `us-east-1`、`cn-east-1` |
| 存储桶 | Bucket 名称，不能含空格或斜杠 | `my-notes` |
| 前缀 | 可选；对象键的前缀 | `notes` |
| Access Key | 访问密钥 ID | — |
| Secret Key | 访问密钥；可点眼睛显示 | — |
| Session Token | 可选；临时凭证使用 | — |
| 路径式地址 | 自建存储通常需要；本机地址会自动使用路径式 | 勾选 |

说明：

- 服务地址必须带 `http://` 或 `https://`（省略时会自动补 `https://`）；
- 地址不能带查询参数、片段或账号密码；
- 存储桶和 Access Key / Secret Key 必填；
- 前缀不能包含空段、`.` 或 `..`；
- 区域留空时使用 `us-east-1`；
- 对象路径为 `前缀/知识库/文件...`（没有前缀时直接是 `知识库/文件...`）；
- 凭据保存在本机设置文件中，文件权限为仅当前用户可读；
- 语燕自己实现 AWS Signature V4，不依赖 AWS SDK。

### 3.1 MinIO / Ceph 示例

```text
服务地址：https://minio.example.com
区域：us-east-1
存储桶：notes
前缀：swift
Access Key：...
Secret Key：...
路径式地址：勾选
```

如果服务使用自签证书，系统可能拒绝连接；请使用受信任证书，或为本机配置信任。

## 4. NFS / SMB 配置

NFS 和 SMB 都要求先在本机挂载共享，再选择挂载后的文件夹。

### 4.1 macOS

- SMB：Finder > 前往 > 连接服务器（`⌘K`），输入 `smb://server/share`，挂载后选择 `/Volumes/...` 下的文件夹。
- NFS：使用系统挂载方式（例如 `mount` 或磁盘工具）挂载后，选择挂载点。

### 4.2 Windows

- 在资源管理器中「映射网络驱动器」，或使用「连接网络驱动器」；
- 选择映射后的盘符或路径。

### 4.3 Linux

- 使用 `mount`、`autofs` 或文件管理器挂载 NFS/SMB；
- 选择挂载后的目录。

### 4.4 路径限制

同步目录必须：

- 已存在且是文件夹；
- 不能位于文档目录内部；
- 不能包含文档目录。

语燕会拒绝这三种情况，避免镜像把自身复制进去，或与笔记目录混在一起。

> **提示**：网络共享在开机时可能还没挂载。启动时如果路径不可用，同步不会启动；挂载恢复后，自动模式会尝试重新启动（约 30 秒后重试）。

## 5. 自动同步与手动同步

### 5.1 自动同步

「自动同步」可选择：

- 15 秒
- 30 秒
- 1 分钟
- 5 分钟
- 关闭（仅手动）

自动模式的行为：

- 应用启动时同步一次；
- 按选定间隔定期检查；
- 保存文档或目录变化后，约 0.7 秒的防抖再同步一次；
- 退出应用前会尽量把最后的修改同步一次。

间隔是“检查频率”，不是每次输入都上传；编辑过程中的连续输入会合并。

### 5.2 仅手动

选择「关闭（仅手动）」后：

- 不会在启动、定时或编辑后自动同步；
- 只有点击「立即同步」才会上传或删除；
- 关闭应用不会触发同步；
- **从回收站彻底删除时，仍会立即删除远端副本**，因为这是明确的删除动作；
- 适合按需备份、流量受限或远端不常在线的情况。

## 6. 测试、立即同步与状态

### 6.1 测试连接

点击「测试连接」，语燕会在远端写入并立即删除一个临时探测对象，用来检查地址、凭据和基本读写权限；它不会写入或修改你的文档内容。

- 成功：显示「连接成功。」
- 失败：显示「连接失败：…」，检查地址、密钥、桶、权限、挂载。

### 6.2 立即同步

点击「立即同步」，语燕会：

1. 校验并保存当前同步设置；
2. 启动同步任务；
3. 比较本地和清单；
4. 上传新增/修改文件，删除远端多余文件；
5. 弹出结果窗口。

结果窗口显示：

- 「远端同步完成」或「远端同步失败」；
- 上传数量和删除数量；
- 如果失败，显示错误详情。

S3 上传和删除遇到 `429`、`500`、`502`、`503`、`504` 或临时网络错误时，会以 0.5 秒、1 秒、2 秒的间隔自动重试，最多尝试 4 次；这能覆盖 CDN 边缘节点的瞬时故障。若错误详情里出现 `<html>` 和 `502 Bad Gateway`（例如 `volc-dcdn`），说明请求到达了对象存储前面的 CDN/反向代理，而不是 S3 源站：先看是否只是瞬时错误，持续出现时请把「服务地址」改成对象存储的 S3 源站地址，或联系服务商确认 CDN 是否允许 PUT 上传。

### 6.3 状态行

设置页底部会显示：

- 等待首次同步；
- 正在同步…；
- 上次同步时间、上传数、删除数、远端文件数；
- 仅手动模式提示；
- 当前远端的描述（例如 `S3 · bucket/prefix`、`NFS · /Volumes/notes`）。

## 7. 删除与回收站

同步会区分“移到回收站”和“彻底删除”：

| 操作 | 远端副本 |
| --- | --- |
| 删除到回收站 | **保留**，以便还原时仍有远端备份 |
| 还原 | 保留，继续同步 |
| 彻底删除 | 立即删除远端副本 |
| 清空回收站 | 逐条删除远端副本 |
| 在应用外删除本地文件 | 下次同步时删除远端副本（如果扫描完整） |

因此，回收站中的内容在彻底删除前可能仍存在于远端，这是预期行为，不是同步失败。

## 8. 同步哪些内容

会同步：

- 知识库中的 `.md` 文档；
- `.assets/` 中的图片和附件；
- 知识库中的其他普通文件；
- 文档子文件夹。

不会同步：

- `.swift/`（回收站、小记、排序、最近打开、阅读位置、同步清单）；
- `.git/`（文档目录根部的版本控制元数据）；
- `.DS_Store`、`Thumbs.db`、临时文件；
- 文档目录根部以 `.` 开头的其他目录；
- 外部知识库（它们不在文档目录中）；
- 小记和 `.swift/note-assets/`；
- 回收站内容；
- 设置文件和诊断日志（它们在系统配置目录）。

> **注意**：小记不在同步范围内。如果你依赖远端备份，请定期把小记保存到知识库，或单独备份 `.swift/note.json`。

## 9. 安全边界和限制

### 9.1 单向镜像

- 远端不是“另一个可编辑副本”，而是本地的镜像；
- 在远端直接修改文件不会被拉回本地，下一次同步可能覆盖或删除它；
- 没有冲突检测、合并、版本历史；
- 多台设备同时写同一个目录时，后同步的设备可能覆盖先同步的内容；
- 需要多端协作时，请使用支持双向/冲突处理的同步工具，或只让一台设备写入。

### 9.2 删除会传播

本地彻底删除后，远端也会删除。若需要防止误删，建议：

- 开启远端存储的版本控制（例如 S3 Versioning）；
- 保留额外的冷备份；
- 不要只把远端当作唯一备份。

### 9.3 凭据

- S3 密钥保存在本机 `config.json`，权限为当前用户可读；
- 不要把配置文件提交到版本控制仓库或分享给他人；
- 建议使用最小权限的 Access Key（只允许目标桶/前缀）；
- 使用 HTTPS Endpoint，避免明文传输；
- 定期轮换密钥。

### 9.4 远端可用性

- 网络共享断开、凭证过期、桶被删除时，同步会失败并显示错误；
- 同步失败不会删除本地文件；
- 为了保护数据，扫描不完整时语燕不会执行远端删除；
- 如果文档目录的 `.swift` 消失（例如磁盘未挂载），已有同步清单时语燕会停止同步，避免误删。

## 10. 常见问题

**Q：同步后远端有文件，但本地没有？**

语燕不会从远端拉取。远端多出的文件可能是以前同步的、回收站保留的，或另一台设备写入的。确认后可以手动清理，或在语燕中彻底删除对应回收站条目。

**Q：为什么删除文档后远端还有？**

它还在回收站。彻底删除或清空回收站后，远端副本才会删除。

**Q：为什么小记没有同步？**

小记在 `.swift/note.json`，同步会跳过 `.swift/`。保存到知识库后才会同步。

**Q：为什么外部知识库没有同步？**

外部知识库不在文档目录中，语燕不会擅自上传。请直接备份原文件夹。

**Q：立即同步提示“同步尚未启动”？**

设置未通过校验，或任务尚未启动。先点「完成」保存设置，再点「立即同步」；查看错误提示。

**Q：测试连接成功，但同步失败？**

测试会写入并删除一个探测对象，能发现基本的连通、凭据和写权限问题；实际同步还涉及对象键、配额和网络稳定性。查看结果窗口的错误详情和诊断日志。

**Q：更换存储桶后为什么要重新上传？**

同步清单与目标绑定。目标变化（Endpoint、桶、前缀）会被视为新的远端，语燕会重新上传全部内容，避免把旧清单误用到新位置。

**Q：同步会加密我的文档吗？**

语燕不额外加密文档；传输是否加密取决于 Endpoint（HTTPS）和远端服务。静态加密请使用磁盘加密或对象存储的服务端加密。

**Q：如何停止同步？**

关闭「启用」并点「完成」。已同步到远端的文件不会被删除。

## 11. 分享文档（PDF）

如果 S3 服务商允许把桶设为「公开读」，语燕可以把单篇文档导出成 PDF 上传，生成一个链接发给别人。PDF 在各种设备上都能直接打开，不依赖语燕，也不用担心对方看到的是 Markdown 源码。

### 11.1 设置分享桶

1. 打开设置（`⌘,`）>「远端同步」；
2. 类型选「S3」，填好服务地址、区域、存储桶和密钥；
3. 在「分享桶（可选）」里填一个**允许公开读取**的桶，前缀默认 `share`；
4. 点「完成」保存。

分享使用上面的服务地址、区域和密钥，只写到分享桶，所以备份桶可以继续保持私有。留空分享桶即关闭分享。

### 11.2 分享一篇文档

1. 打开文档，点右上角的分享按钮；
2. 选择有效期：1 天、3 天、7 天或永久；
3. 点「生成分享链接」，复制链接发给别人。

点「生成」后，语燕先用和「导出 PDF」相同的管线把文档渲染成 PDF（通常几秒），再上传到分享桶。分享出去的 PDF 文件名就是当前文档标题。再次点「重新分享」会生成新链接并删掉旧文件；「撤销分享」会删除 PDF。

### 11.3 有效期怎么实现

| 选择 | 链接 | 到期后 |
| --- | --- | --- |
| 1 / 3 / 7 天 | 预签名 URL，权限只到选定的时间 | 链接自动失效 |
| 永久 | 对象的公开地址 | 一直有效，直到撤销或重新分享 |

1/3/7 天的链接由签名控制，到期后即使文件还在桶里也打不开；永久链接要求分享桶开启公开读，没开启时语燕会提示「分享桶没有开启公开访问」，并且不会生成链接。

### 11.4 文件与记录

- 分享文件是 `share/<随机 ID>/<文档标题>.pdf`：随机目录让链接猜不到，文件名用文档标题，对方下载后拿到的就是「文档标题.pdf」；标题里的 `/`、`:` 等非法字符会替换成 `-`，空标题用「未命名」；
- 分享记录保存在文档目录的 `.swift/shares.json`，不参与同步；
- 分享页（PDF）在服务商那边的公开地址通常会让浏览器下载后打开，这是正常行为；
- 过期的 PDF 会在启动时以及运行期间每小时清理；没有运行语燕时不会清理，但签名链接本身已经失效。

### 11.5 限制

- PDF 的排版和编辑器里可能略有差异（表格、Mermaid 等，见[导出](11-export.md)）；
- 文档里的附件和指向其他文档的链接不会上传，PDF 里会打不开；
- 分享是公开的：任何拿到链接的人都能查看，没有密码；
- 分享桶如果允许匿名列举对象，别人能看到桶里的 PDF。建议分享桶只放分享内容，并在服务商那边关闭匿名列目录。
