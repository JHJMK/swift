# 目录与文档树

[返回教程目录](README.md) · [返回项目主页](../README.md)

语燕用「知识库 → 目录 → 文档」的树形结构组织内容。与普通文件夹不同，**文档本身也可以有子文档**，这类子文档保存在与文档同名的文件夹里，但在界面上仍显示在文档下面。

## 1. 树的层级

```text
知识库（顶层文件夹）
├── 目录 A
│   ├── 文档 1.md
│   └── 目录 B
│       └── 文档 2.md
├── 文档 3.md
│   └── 子文档 3-1.md      ← 磁盘上位于 文档 3/ 文件夹
└── 文档 4.md
    └── 目录 C
        └── 子文档 4-1.md
```

规则：

- 知识库以下最多 **4 级**（知识库本身不算一级）。
- 文档可以像目录一样拥有子项；子项与文档同名文件夹中的内容对应。
- 超过 4 级时，语燕不会提供「添加」菜单，拖动或粘贴也会提示「目录最多支持 4 个层级」。
- 树中不显示隐藏文件夹、`.assets/` 和 `.swift/`；这些是语燕的内部结构。

> **提示**：如果你不需要子文档，完全可以把所有文档都放在目录里。子文档适合“一篇主文档 + 若干补充材料”的场景，例如「项目计划」下面挂「需求」「排期」「复盘」。

## 2. 新建目录 / 分组

「目录」和「分组」是同一个东西，只是不同入口的措辞不同：

| 入口 | 菜单文字 | 新文件夹位置 | 默认名称 |
| --- | --- | --- | --- |
| 知识库标题右侧 `+` | 新建目录 | 当前知识库根目录 | 新目录 |
| 目录树行尾 `+` | 分组 | 该节点下面 | 新分组 |
| 知识库 / 目录首页 | 新建目录 | 当前知识库或目录 | 新目录 |
| 菜单栏 文件 > 新建目录 | 新建目录 | 选中的是目录时放在其中；选中的是文档时放在它所在目录（同级） | 新目录 |

操作：

1. 打开合适的入口。
2. 输入名称，点击「创建」或按 `Enter`。
3. 如果父级是折叠的，语燕会自动展开它并选中新目录。

命名会自动清理非法字符；同名目录会变成「名称 2」。

## 3. 新建文档

### 3.1 不同入口的区别

| 入口 | 行为 |
| --- | --- |
| 工作台「新建文档」 | **先弹出位置选择器**，选择知识库、目录或文档，再创建 |
| 知识库标题右侧 `+` > 新建文档 | 直接在当前知识库根目录创建「无标题文档」 |
| 目录树行尾 `+` > 文档 | 直接在当前节点下创建「无标题文档」 |
| 目录 / 知识库首页「新建文档」 | 直接在当前目录或知识库中创建 |
| 菜单栏 文件 > 新建文档（`⌘N`） | 选中的是目录时放在目录中；选中的是文档时放在它所在目录（同级）；没有选中项时放在第一个知识库 |
| 文档页标题 | 输入标题后自动重命名当前文档，不会新建文档 |

> **提示**：工作台的「新建文档」是最明确的选择位置方式；如果你已经选中了目标目录，用 `⌘N` 更快。

### 3.2 位置选择器

工作台新建文档时会打开一个选择器：

- 列出全部知识库、目录和文档。
- 选择知识库或目录：文档创建在它下面。
- 选择一篇文档：文档会成为这篇文档的子文档（自动创建同名文件夹）。
- 如果还没有任何知识库，语燕会弹出「创建第一篇文档」对话框，可以同时为知识库和第一篇文档命名；标题留空时会创建「无标题文档」，打开后在标题栏输入即可。

选择器会预选一个默认位置；也可以改选知识库、目录或文档，再点「创建」。「取消」不会创建任何东西。

### 3.3 无标题文档与标题

新文档以「无标题文档」命名，打开后标题栏为空并获得焦点，直接输入即可。若保持为空离开，文档仍叫「无标题文档」；再次重命名时会使用新名称。

输入标题后：

- 按 `Enter` 或点击正文，标题会立即生效；
- 文档文件名同步改变，并保留 `.md` 后缀；
- 如果当前文档有子文档，同名子文件夹也会一起改名；
- 文档自己的页面设置（行距、字号覆盖）会跟随新路径；跟随全局的文档继续跟随全局。

也可以随时在目录树中右键或 `…` > 「重命名」修改标题，效果相同。

## 4. 在树中操作

### 4.1 展开、收起、选中

- 点击节点：选中并打开。目录打开目录页，文档打开编辑页。
- 点击节点前的箭头：只展开/收起，不改变选中项。
- 新打开的知识库默认展开顶层，深层目录默认折叠。
- 打开文档时，语燕会自动展开它上面的所有父目录，让它在树中可见。

### 4.2 行尾操作

鼠标悬停在某一行上，或该行被选中时，右侧出现两个按钮：

- **添加（`+`）**：新建文档、新建分组、导入文档。
- **更多操作（`…`）**：重命名、复制、粘贴、复制链接、置顶、移出目录、导出、在 Finder 中显示、删除。

右键点击整行也会打开同一个「更多操作」菜单。不同节点的菜单项略有不同：

| 操作 | 文档 | 目录 / 分组 | 说明 |
| --- | --- | --- | --- |
| 重命名 | 有 | 有 | 外部知识库的文档/子目录也提供；外部知识库根节点不提供 |
| 仅复制本资源 | 有 | 有 | 只复制当前文件或空文件夹 |
| 复制全部子资源 | 有 | 有 | 连同子项一起复制，可能受 4 级限制 |
| 粘贴 | 有（可接纳子项时） | 有（可接纳子项时） | 把之前复制的资源粘贴到这里 |
| 复制链接 | 有 | 无 | 复制 `file://` 本地文件链接 |
| 置顶文档 | 有 | 无 | 把文档移到同级最前面 |
| 移出目录 | 位于子目录中时有 | 位于子目录中时有 | 上移一级 |
| 导出 Markdown / PDF | 有 | 无 | 导出整个知识库请用知识库行或知识库首页的「导出」 |
| 在 Finder 中显示 | 有 | 有 | 用系统文件管理器定位 |
| 删除 | 有 | 有 | 移到回收站；外部知识库中的删除会移动原文件 |

### 4.3 拖动

拖动树中的节点时，松开的位置决定结果：

- **拖到某行的上半部或下半部**（出现一条横线）：插入到该行的上方或下方，即同级排序；跨目录拖动时是移动到目标所在目录的对应位置。
- **拖到目录行的中间**：成为该目录的子项。
- **拖到文档行的中间**：成为该文档的子文档（必要时自动建立同名文件夹）。
- 拖动后会检查层级限制；超过 4 级时不会执行，并显示错误提示。

知识库在左侧栏的「知识库」列表中拖动排序：拖到某个知识库的上半部排在它上面，下半部排在它下面。外部知识库也参与排序，它的文件夹仍在原地，不会被移动。

> **注意**：把文档拖到不同层级时，正文中的相对图片路径不会自动重写（图片通常以 `../.assets/...` 这类相对路径保存）。如果移动后图片不显示，请把图片重新插入，或手动修正 Markdown 中的路径。移动整个目录不受影响，因为目录内部的相对关系没有变。

### 4.4 复制与粘贴

这里的「复制」是语燕内部的资源剪贴板，不是系统剪贴板：

1. 在某一行 `…` > 「仅复制本资源」或「复制全部子资源」。
2. 到目标目录或文档的 `…` > 「粘贴」，或在知识库 `+` > 「粘贴」。
3. 语燕会在目标位置创建副本。

行为说明：

- **仅复制本资源**：文档复制 `.md`，并把正文里的图片/附件引用重写到目标位置（跨知识库时会复制资源）；目录只创建空目录。
- **复制全部子资源**：连同子文档、子目录一起复制。
- 粘贴到文档时，内容会成为该文档的子项。
- 复制到另一个知识库时，文档引用的本地图片和附件会复制到目标知识库的 `.assets/`，并改写链接。
- 同名副本会自动编号。
- 资源剪贴板只在本次运行中有效；退出语燕后需要重新复制。
- 达到 4 级限制时不会粘贴。

### 4.5 置顶与移出

- **置顶文档**：把文档移动到同一层的最前面。如果它已经在最前面，菜单执行后位置不变。
- **移出目录**：把节点上移一级；位于知识库第一层时没有这个菜单项。适合把误放进子目录的文档提出来。

### 4.6 复制链接

文档的 `…` > 「复制链接」会把本地文件路径复制为 `file://` 链接，例如：

```text
file:///Users/you/Documents/notes/工作笔记/项目计划.md
```

这是本地文件链接，不是可分享的网页地址。粘贴到其他本地应用时能否打开，取决于对方是否支持 `file://`。

### 4.7 删除

删除会把节点移到回收站：

- 删除文档时，和它同名的子文档文件夹会一起进入回收站。
- 删除目录时，整个目录及内部内容一起进入回收站。
- 删除知识库见[知识库管理](03-knowledge-bases.md)。
- 删除后如果当前打开的文档在其中，编辑器会关闭它，并尽量选中上层仍然存在的节点。
- 外部知识库的「引用」本身不在回收站流程内；移除引用不会删除原文件夹。但在外部知识库中删除文档/目录时，原文件会被移到语燕回收站，请确认影响范围。

## 5. 文档的子文档

这是语燕与普通文件夹最不一样的地方，值得单独说明。

### 5.1 磁盘上的样子

假设文档 `项目计划.md` 有两个子文档：

```text
工作笔记/
├── 项目计划.md
└── 项目计划/
    ├── 需求.md
    └── 排期.md
```

树中显示为：

```text
工作笔记
└── 项目计划
    ├── 需求
    └── 排期
```

`项目计划/` 文件夹不会单独显示成一行；它作为 `项目计划` 文档的子项容器。

### 5.2 创建子文档

- 在文档行 `+` > 「文档」：在该文档下创建子文档。
- 在文档行 `+` > 「分组」：在该文档下创建子目录。
- 把其他文档或目录拖到文档上。
- 从工作台新建文档时，在选择器中选择某篇文档。

### 5.3 移动、重命名、删除

- 重命名文档：同名文件夹一起改名，子文档仍在其中。
- 移动文档到其他目录：文件夹随文档一起移动；但正文中的相对图片路径可能失效（见 4.3 的注意）。
- 删除文档：文档和同名文件夹一起进入回收站。
- 还原：两者一起回到原位置；如果原路径已被占用，还原会失败并保留回收站条目。

### 5.4 适合与不适合

适合：

- 一篇主文档下挂若干补充材料；
- 项目文档下挂会议记录、需求、复盘；
- 不希望子项出现在目录列表里，只想在打开主文档时看到。

不适合：

- 需要被其他目录直接引用的公共资料（放到普通目录更合适）；
- 需要超过 4 级的深层结构（请拆分成多个知识库或目录）。

## 6. 空状态

- 知识库没有内容：目录树显示「还没有文档」。
- 目录为空：目录页显示「这个目录还是空的」，并提供新建文档的提示。
- 没有知识库：侧栏显示「还没有知识库」，并提供创建按钮。

空状态中的按钮都可以直接使用，不需要先通过菜单。

## 7. 整理建议

- 先在知识库首页建立一级目录，再往里放文档，比把所有文档堆在根目录更容易维护。
- 知识库层级不要超过 3–4 级；更深的分类往往意味着应该拆成新的知识库。
- 常用入口文档用「置顶文档」放在最前面。
- 需要跨知识库复用的内容，复制全部子资源到目标知识库，让图片一起过去。
- 用「移出目录」纠正放错层级的内容，不必删除重建。
