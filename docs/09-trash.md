# 回收站

[返回教程目录](README.md) · [返回项目主页](../README.md)

在语燕中删除文档、目录或知识库时，内容会先进入**回收站**。这是一层保护：误删后可以还原，只有「彻底删除」或「清空回收站」才会真正移除文件。

## 1. 删除后发生了什么

删除操作会：

1. 把文件或文件夹从原位置移动到文档目录下的 `.swift/trash/<条目ID>/`；
2. 写入一条元数据（名称、原路径、是否目录、删除时间）；
3. 从目录树中移除；
4. 在回收站中显示为一条记录。

此时：

- 原路径不再存在；
- 文件内容仍在磁盘上；
- 可以通过回收站还原；
- 不占用新的“回收站配额”，只是占用磁盘空间；
- 条目会一直保留，直到你手动清理。

## 2. 打开回收站

点击左侧侧栏「回收站」。

回收站是一个弹窗，列出全部条目：

- 名称；
- 原路径；
- 删除时间（本地时间）；
- 「还原」「彻底删除」按钮；
- 顶部「清空回收站」和「关闭」。

条目按删除时间从新到旧排列。

## 3. 还原

点击条目右侧「还原」：

- 语燕把内容放回**原来的位置**；
- 如果原路径的父目录不存在，会先创建父目录；
- 如果原路径已被另一个同名文件占用，还原失败，并显示错误；
- 文档及其子文档文件夹会一起还原；
- 目录及其内部内容会一起还原；
- 知识库会整体还原。

还原成功后，条目从回收站消失，目录树刷新，选中项可能回到父级。

> **提示**：如果还原失败，通常是因为原位置已经有同名内容。可以先重命名当前占用者，或把回收站条目彻底删除/导出后再处理。

## 4. 彻底删除

点击条目右侧「彻底删除」，系统会弹出确认框：

- 「删除」：永久删除该条目；
- 「取消」：保留在回收站。

彻底删除会：

- 删除条目中的文件或文件夹；
- 清理这篇（些）文档引用、且不再被其他内容引用的图片和附件；
- 如果共享图片仍被其他文档或回收站条目引用，则保留；
- 无法通过语燕恢复。

> **注意**：彻底删除是不可逆的。若启用了远端同步，语燕会同时删除远端的对应副本；如果远端存储本身有版本控制或回收机制，能否恢复取决于远端服务，语燕不提供恢复入口。

## 5. 清空回收站

点击顶部「清空回收站」，会弹出确认框，显示将被永久删除的条目数量。

- 「清空」：逐条彻底删除回收站中的全部内容；
- 「取消」：不做任何修改。

清空同样会清理不再被引用的图片和附件。清空后无法在语燕内恢复。

## 6. 图片和附件如何清理

语燕不会在“移到回收站”时立即删除图片，因为还原后还需要它们。只有**彻底删除**时才会检查：

1. 收集被删除文档中引用的本地图片和附件；
2. 扫描仍然存在的文档（包括外部知识库）中的引用；
3. 扫描其他回收站条目中的引用；
4. 只有当某个资源不再被任何地方引用时，才从 `.assets/` 中删除。

因此：

- 两张文档共用一张图片，删除其中一张并彻底删除，图片会保留；
- 图片只被已删除的文档引用，彻底删除文档后图片也会被清理；
- 回收站中另一个条目还引用同一张图片时，图片会保留，以便它还能还原；
- 知识库整体删除时，它的 `.assets/` 在条目内部，会随知识库一起删除。

## 7. 删除和回收站的边界

| 内容 | 是否进入回收站 |
| --- | --- |
| 普通文档 | 是 |
| 文档的子文档和同名文件夹 | 是，随文档一起 |
| 目录 / 分组 | 是，含全部内容 |
| 普通知识库 | 是，含全部内容 |
| 外部知识库的引用 | 否；「移除外部知识库」只移除引用 |
| 外部知识库中的文档 / 目录 | 是；原文件夹中的文件会被移走 |
| 小记 | 否；小记不在知识库中 |
| 设置、日志、同步记录 | 否 |

外部知识库的“引用”本身不进入回收站，移除引用不会删除原文件；但在外部知识库中删除某篇文档或子目录时，语燕会把原文件移到语燕回收站，原文件夹中不再保留它。请在操作前确认影响范围。

## 8. 回收站与远端同步

- 回收站本身位于 `.swift/`，**不会被同步**；
- 文档刚删除到回收站时，远端副本会暂时保留，以便还原时不丢数据；
- 从回收站彻底删除或清空时，语燕会通知同步任务删除远端对应文件；
- 因此，“移到回收站”不等于“从远端删除”；只有彻底删除才会。
- 如果在另一台设备上查看远端，回收站中的内容在彻底删除前可能仍然存在，这是预期行为。

详见[远端同步](12-remote-sync.md#7-删除与回收站)。

## 9. 常见问题

**Q：回收站会占满磁盘吗？**

不会自动设限。条目会一直占用磁盘，直到彻底删除或清空。建议定期清理不再需要的内容。

**Q：回收站有保留期限吗？**

没有。语燕不会自动删除回收站条目；需要你手动清空。

**Q：误删后还能恢复吗？**

只要还没有彻底删除/清空，就可以在回收站里还原。若已彻底删除，语燕内无法恢复；请检查备份或远端存储的版本历史。

**Q：删除文档后，为什么图片还在？**

因为图片可能被其他文档或其他回收站条目引用，或者你还没有执行彻底删除。参考第 6 节。

**Q：能预览回收站里的文档吗？**

不能。当前回收站只提供列表、还原和删除。需要查看内容时，先还原。

**Q：还原时提示“已存在，无法还原”怎么办？**

原位置已有同名文件或文件夹。可以先重命名当前内容，或把回收站条目导出/处理后再还原。语燕不会覆盖现有内容。

**Q：能恢复整个知识库吗？**

可以，只要知识库还在回收站中且原路径可用。点击它的「还原」即可整体恢复。

**Q：清空回收站能撤销吗？**

不能。清空是永久删除；请在确认框中仔细核对。
