# 知识库管理

[返回教程目录](README.md) · [返回项目主页](../README.md)

知识库是语燕组织内容的第一层。一个知识库对应文档目录中的一个顶层文件夹，下面可以放目录、文档和子文档。

## 1. 知识库是什么

- **一个知识库 = 文档目录下的一个顶层文件夹。**
- 每个知识库有独立的 `.assets/` 文件夹，存放这个知识库的图片和附件。
- 知识库之间互相独立：复制文档到另一个知识库时，图片会被复制到目标知识库。
- 知识库可以导出为 ZIP，也可以从文件夹复制导入。

```text
文档目录/
├── 工作笔记/          ← 知识库
│   ├── 项目计划.md
│   ├── 会议/
│   └── .assets/       ← 这个知识库的图片和附件
├── 学习资料/          ← 另一个知识库
└── .swift/            ← 语燕的元数据，不属于任何知识库
```

## 2. 新建知识库

有三种入口：

1. **全局侧栏**：点击「知识库」右侧的 `+`，选择「新建知识库」。
2. **工作台**：点击「新建知识库」卡片。
3. **菜单栏**：文件 > 新建知识库。

输入名称后点击「创建」，语燕会：

- 在文档目录中创建同名文件夹；
- 把它加入侧栏和目录树；
- 在侧栏和目录树中显示这个知识库；新知识库是空的，可以从知识库首页新建文档。

### 命名规则

- 名称会自动去掉首尾空白，并把 `/ \ : * ? " < > |` 等文件名非法字符替换为 `-`。
- 名称最长 100 个字符；为空时使用「未命名」。
- 同名知识库不会覆盖，会自动变成「名称 2」「名称 3」。
- 重命名会改变磁盘上的文件夹名，并同步更新打开文档的路径和页面设置。

> **提示**：知识库名称就是文件夹名。如果你会在 Finder / 资源管理器中直接管理文件，建议使用简短、稳定的名称。

## 3. 打开知识库

- 点击侧栏中的知识库名称：打开这个知识库，并自动打开其中的第一篇文档。
- 点击目录树中的「首页」：打开知识库首页，不打开文档。
- 知识库首页会显示名称、路径和子项列表；可以在这里新建文档或目录。

「自动打开第一篇文档」的查找顺序是：

1. 目录树中第一个文档（包括子目录中的文档）；
2. 没有文档时，保持知识库首页。

如果你想固定从某篇文档开始，可以把那篇文档拖到知识库的最前面，或使用「置顶文档」。

## 4. 重命名知识库

普通知识库可以重命名：

- 在侧栏知识库行悬停，点击 `…` > 「重命名」；
- 或打开知识库，点击标题右侧的 `+` > 「重命名知识库」。

重命名只改变文件夹名，不会改变内部的 Markdown 内容；如果当前打开的是这个知识库中的文档，标题和路径会自动跟随。外部知识库的根节点不能重命名，详见下文。

## 5. 导出知识库

在侧栏知识库行点击 `…` > 「导出」，或在知识库首页的「更多」中选择导出，语燕会：

1. 让你选择保存位置；
2. 把整个知识库文件夹（包括 `.assets/` 和所有文档）打包为 ZIP；
3. 默认文件名为 `<知识库名>.zip`；
4. 跳过 `.DS_Store`，保留其他普通文件。

导出的 ZIP 是普通目录结构，解压后可以直接用 Markdown 工具打开。详细说明见[导出](11-export.md)。

> **注意**：不能把知识库导出到它自己的文件夹内部；语燕会拒绝这种路径，避免把 ZIP 打包进正在读取的目录。

## 6. 删除知识库

在侧栏知识库行点击 `…` > 「删除」，或知识库首页「更多」> 「删除」，确认后知识库会**移到回收站**，而不是立即删除。

- 知识库中的全部文档、子目录和 `.assets/` 会一起进入回收站。
- 可以在回收站中还原，原路径和内容保持不变。
- 在回收站中「彻底删除」或「清空回收站」才会真正删除文件，并清理不再被引用的资源。
- 删除后，如果当前打开的文档属于这个知识库，编辑器会关闭它，并尽量选中上层的知识库或文档。

详见[回收站](09-trash.md)。

## 7. 外部知识库（引用已有文件夹）

除了把文件夹复制进文档目录，语燕还可以**引用**文档目录之外的文件夹。这适合：

- 已经在其他 Markdown 工具中维护的笔记目录；
- 放在移动硬盘、共享盘上的资料；
- 不希望复制一份、希望语燕和原工具共用同一批文件的场景。

> **注意**：外部知识库是**可读写的活引用**，不是只读副本。在语燕中编辑文档、重命名或删除文档，会直接作用在原文件夹上。若只想查看而不影响原文件，请使用「复制导入知识库」。

### 7.1 添加外部知识库

1. 点击侧栏「知识库」右侧 `+` > 「导入」> 「引用外部知识库」；
2. 或工作台「导入知识库」> 「引用外部知识库」；
3. 或菜单栏 文件 > 引用外部知识库…；
4. 选择一个文件夹。

语燕会在侧栏中增加一个同名知识库，并记住这个文件夹的位置。文件夹本身**不会**被复制，也不会被移动。

### 7.2 外部知识库的特点

| 特性 | 普通知识库 | 外部知识库 |
| --- | --- | --- |
| 文件位置 | 文档目录内部 | 原文件夹，位置不变 |
| 文档编辑 | 可编辑，写入文档目录 | 可编辑，**直接写回原文件夹** |
| 新建文档 / 子目录 | 支持 | 支持，文件创建在原文件夹 |
| 重命名文档 / 子目录 | 支持 | 支持，会改原文件夹中的名称 |
| 删除文档 / 子目录 | 移到回收站 | 移到语燕回收站，原文件夹中的文件会消失 |
| 重命名知识库根节点 | 支持 | 不提供；请直接重命名原文件夹后重新引用 |
| 搜索 | 支持 | 支持 |
| 导出 | 支持 | 支持 |
| 远端同步 | 参与 | **不参与** |
| 目录监视 | 参与 | 参与（原文件夹的变化会刷新） |

「外部引用」是状态标记，不是只读锁。编辑外部文档时，顶部仍显示格式工具栏，保存会写回原文件。

### 7.3 与原工具共同编辑

- 外部知识库适合“语燕和原工具共用同一批文件”；
- 不要在语燕和其他编辑器中同时修改同一篇文档；
- 在外部工具中修改后，语燕会通过目录监视重新载入；
- 如果语燕有未保存内容，外部修改不会覆盖本地编辑，页面会提示冲突；
- 外部知识库中的图片路径、附件路径由原目录决定，语燕不会把它们复制到文档目录的 `.assets/`。

### 7.4 移除外部知识库

在侧栏外部知识库行点击 `…` > 「移除外部知识库」，或在知识库首页「更多」中选择「移除外部知识库」。

- 只会从语燕的知识库列表中移除引用；
- 原来的文件夹和文件不会被删除；
- 以后可以再次引用同一个文件夹；
- 如果移除时正在查看其中的文档，编辑器会关闭该文档；
- 这和“删除外部知识库中的某篇文档”不同：后者会移动原文件。

如果外部文件夹被移动、删除或所在磁盘未挂载，语燕启动时不会列出这个知识库；恢复文件夹位置或重新引用即可。

### 7.5 为什么外部知识库不参与同步

远端同步只镜像文档目录内部的内容。外部知识库的原文件不在文档目录中，语燕不会擅自上传它们。若需要备份外部资料，请直接备份原文件夹，或使用「复制导入知识库」后再同步。

## 8. 知识库的顺序和统计

- 新建的知识库默认追加在知识库列表末尾。
- 在侧栏拖动知识库可以调整它们之间的顺序；知识库只能和其他知识库排序，不能拖进别的目录。
- 外部知识库和本地知识库一起排序：首次引用、还没有拖动过顺序时，外部知识库排在列表末尾并按名称排序；拖动后按其位置保存，文件夹本身不动。
- 工作台顶部的「N 个知识库 · M 篇文档」会统计本地和外部知识库中的文档。
- 排序信息保存在 `.swift/order.json`，重启后保持。

## 9. 使用建议

- 一个知识库对应一个相对稳定的主题，例如「工作」「学习」「个人项目」。不要把完全无关的内容塞进同一个知识库。
- 需要跨工具维护的目录用「引用外部知识库」；需要语燕完整管理、同步和编辑的目录用「复制导入知识库」。
- 知识库名称不建议频繁修改；外部工具、脚本或链接可能依赖文件夹名。
- 在删除知识库前，先确认回收站可用，并考虑先导出 ZIP 作为额外备份。
