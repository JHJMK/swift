# 常见问题

[返回教程目录](README.md) · [返回项目主页](../README.md)

本章按使用场景汇总常见问题。遇到问题时，先找到对应分类；如果仍然无法解决，见文末的反馈方式。

## 1. 安装与启动

### Q1. 启动后一直显示“选择文档目录”？

说明语燕还没有可用的工作区，常见原因：

- 第一次使用，尚未选择目录；
- 配置文件被删除；
- 原来选择的目录被移动、重命名或所在磁盘未挂载。

重新选择目录即可。原有文件不会被删除。

### Q2. 界面空白或编辑器没有加载？

默认编辑器依赖系统 WebView：

- macOS：WKWebView（系统自带）；
- Windows：WebView2 运行时；
- Linux：WebKitGTK。

如果 WebView 不可用，语燕会尝试回退到内置原生编辑器。若界面仍然空白，请更新系统或安装对应的 WebView 运行时，并查看诊断日志。

### Q2.1 点了关闭按钮，语燕是不是退出了？

没有。窗口会隐藏到后台，自动保存和同步继续运行。macOS 点菜单栏的语燕图标或 Dock 图标，Windows 点通知区域托盘图标即可重新打开。真正退出请在托盘/菜单栏菜单中选「退出语燕」。

### Q3. macOS 提示“无法验证开发者”？

这是未签名/未公证应用的系统提示。确认安装包来源可信后，可以在「系统设置 > 隐私与安全性」中允许打开，或右键应用选择「打开」。自行构建的开发版通常没有签名。

### Q4. Windows 提示 SmartScreen？

确认文件来源可信后，点击「更多信息」>「仍要运行」。不要绕过来源不明的可执行文件。

### Q5. 语燕会上传我的笔记吗？

默认不会。只有你主动启用远端同步、导入 Lakebook 图片、打开外部链接，或文档加载网络图片时才会联网。没有账号系统，也没有遥测。

## 2. 写作与编辑

### Q6. 为什么没有保存按钮？

语燕自动保存：停止输入约 0.6 秒后写入磁盘。顶部和底部状态会显示「已保存」或「保存失败」。切换文档和退出前也会尝试保存。

### Q7. 为什么当前行的 `**`、`#` 又出现了？

这是实时预览的行为：光标所在行显示 Markdown 源码，方便精确修改；光标离开后恢复渲染。它不是格式丢失。

### Q8. 为什么页面里出现了两个一样的标题？

页面顶部的大标题是文档标题（文件名）；正文里的 `# 标题` 是另一个 H1。两者是不同内容。只想要一个标题时，正文从 `##` 开始，或删除正文 H1。

### Q9. 支持哪些 Markdown？

支持常用 Markdown 语法，外加高亮、任务列表、Mermaid、双链样式等。不是完整的双链笔记工具：提示块、块引用、数据库视图、白板、数学公式等不支持。详见[Markdown 与内容块](06-markdown-and-blocks.md)。

### Q10. 为什么 `[[双链]]` 点了不跳转？

当前版本只提供双链的显示样式，没有反向链接、图谱和跳转面板。需要跳转时用普通 Markdown 链接或全局搜索。

### Q11. 支持数学公式吗？

不支持公式渲染。公式会作为普通文本显示；需要公式时，可以先把公式渲染为图片，再插入文档。

### Q12. 中文输入法有问题吗？

编辑器处理了输入法组合事件，正常的中文输入、候选词和标题输入都可以使用。如果遇到特定输入法问题，请记录系统、输入法和复现步骤并反馈。

### Q13. 能恢复撤销历史吗？

撤销只在当前编辑会话中有效，且不是文档版本历史。关闭文档或重启后，无法通过撤销找回旧版本。重要内容请使用备份。

### Q14. 能同时打开多篇文档吗？

当前是单窗口、单文档编辑：切换文档会自动保存。没有多标签页；需要对照时可以在系统里再启动一个实例，但不建议同时编辑同一篇文档。

## 3. 文件和附件

### Q15. 为什么放在文档目录根部的 `.md` 文件不显示？

语燕把**顶层文件夹**当作知识库，根部的散落 `.md` 不会进入树。把它们放进一个文件夹，再用「复制导入知识库」或直接在该文件夹中维护。

### Q16. `.assets` 和 `.swift` 是什么？能删吗？

- `.assets/`：知识库的图片、附件和 Mermaid 缓存；删除会导致文档图片/附件失效。
- `.swift/`：排序、最近打开、阅读位置、小记、回收站、同步清单；删除会丢失这些状态。

两者都是隐藏目录。不要为了“整洁”删除或重命名它们。

### Q17. 图片不显示怎么办？

依次检查：

1. 文件是否还在 `.assets/`；
2. Markdown 中的路径是否正确；
3. 文档是否被跨层级移动（相对路径可能失效）；
4. 网络图片是否能访问；
5. 系统 WebView 是否支持该图片格式。

修复方法：重新插入图片、修正路径，或把图片放到知识库的 `.assets/`。

### Q18. 移动文档后图片坏了？

图片通常用相对路径引用。移动到不同层级后，`../.assets/...` 的相对位置可能不再成立。把图片重新插入，或手动调整 Markdown 路径。移动整个目录一般不会破坏内部相对关系。

### Q19. 外部知识库能编辑吗？

能，而且会直接写回原文件夹。外部知识库是活引用，不是只读副本；状态显示「外部引用」。如果只想查看或需要独立副本，请使用「复制导入知识库」。

### Q20. 文档最多几级？

知识库以下最多 4 级（包括子文档）。更深的目录仍在磁盘上，但树不会显示，建议整理到 4 级以内。

### Q21. 在 Finder 里改了文件名，语燕会跟着变吗？

当前知识库有文件监视，通常会刷新并跟随重命名/移动。如果没有反映，切换一下知识库或重启语燕。为减少相对路径问题，建议在语燕内重命名和移动。

## 4. 搜索

### Q22. 搜索不到小记？

小记不在知识库中，不参与搜索。先「保存到」知识库。

### Q23. 搜索不到刚写的内容？

确认文档已保存（状态为「已保存」），并检查搜索范围是否被限定。搜索没有索引，刚写入的文件通常很快可见。

### Q24. 能搜索 PDF/Word 附件里的文字吗？

不能。搜索只读取 `.md` 文本；附件内容不会被解析。

### Q25. 为什么只返回 50 条？

这是当前上限。请缩小范围或使用更具体的关键词。

## 5. 导入与导出

### Q26. Lakebook 导入失败？

可能原因：

- 文件不是有效的 Lakebook tar 归档；
- 归档损坏、节点类型不支持或层级超过 4 级；
- 文件超过大小限制（压缩 32MB / 解压 256MB / 2000 条目）。

查看错误提示；图片下载失败不会导致整体失败，会在结果中显示数量。详见[导入](10-import.md#4-导入-lakebook)。

### Q27. 导入的 Lakebook 画板不能编辑？

Lakebook 画板会转换为静态文档，保留标题、文字、预览图和原链接，但不支持交互绘图。这是设计限制。

### Q28. `.doc` 为什么不能导入？

只支持 `.docx`。请用 Word/WPS 另存为 `.docx` 后再导入。

### Q29. TXT 导入乱码？

文件编码可能不是 UTF-8 或 GB18030。用文本编辑器另存为 UTF-8 后重试。

### Q30. 导出的 PDF/Word 和页面不一样？

PDF 由打印样式生成，Word 是转换稿，二者都不保证像素级一致。复杂表格、Mermaid、字体和分页可能不同。需要完整保真时导出 Markdown。

### Q31. 导出的图片打不开？

Markdown ZIP 中图片在 `<标题>.assets/`，必须和 `.md` 保持相对位置；移动 `.md` 时不要只移动它一个文件。知识库 ZIP 解压后整体使用即可。

## 6. 回收站

### Q32. 删除的文件去哪了？

在回收站。可以还原，或彻底删除/清空。只有彻底删除才释放磁盘空间并删除远端副本。

### Q33. 在 Finder 里删除的文件能找回吗？

不能通过语燕回收站找回。回收站只记录语燕内的删除操作；请从系统废纸篓/回收站或备份恢复。

### Q34. 清空回收站后还能恢复吗？

不能。语燕没有回收站历史版本；只能依赖备份或远端服务的版本控制。

### Q35. 删除文档后图片为什么还在？

可能仍被其他文档或回收站条目引用；或者你还没有彻底删除。彻底删除会清理不再被引用的资源。

## 7. 远端同步

### Q36. 同步是双向的吗？

不是。语燕只把本地镜像到远端，不会把远端改动拉回本地。多设备同时写同一目录可能互相覆盖。

### Q37. 为什么删除了文档，远端还有？

文档还在回收站。彻底删除或清空回收站后，远端副本才会删除。

### Q38. 为什么小记/外部知识库没有同步？

- 小记在 `.swift/` 中，同步跳过 `.swift/`；
- 外部知识库不在文档目录中，语燕不会上传。

### Q39. 测试连接成功，同步却失败？

测试会写入并删除一个临时探测对象，能检查基本连接、凭据和写权限；实际同步还需要正确的桶/前缀、配额和稳定网络。查看结果窗口的错误和日志。

### Q40. 同步目录不能放在文档目录里？

这是保护措施：如果同步目录位于文档目录内部，镜像可能把自身复制进去，或与笔记混在一起；反过来包含文档目录也会导致混乱。

### Q41. 同步能替代备份吗？

不建议只依赖同步。同步会把本地彻底删除传播到远端；请额外保留冷备份，或使用远端版本控制。

### Q42. 换电脑后如何继续同步？

复制文档目录并重新配置同步；同步清单 `.swift/sync-state.json` 可以保留，但目标地址/桶/前缀变化会触发重新上传。

## 8. 数据和隐私

### Q43. 数据到底存在哪？

- 文档：你选择的文档目录；
- 设置：系统配置目录 `Swift/config.json`；
- 日志：系统配置目录 `Swift/logs/`。

详见[设置与数据](13-settings-and-data.md)。

### Q44. 如何备份？

退出语燕后复制整个文档目录；需要设置时再复制 `config.json`。或导出知识库 ZIP。重要内容建议保留多个备份。

### Q45. 能加密笔记吗？

语燕没有应用级文档加密或密码锁。请使用系统磁盘加密（FileVault、BitLocker、LUKS）、受保护的账户，或把文档放在加密卷中。

### Q46. 配置文件能分享吗？

不要。它可能包含 S3 Access Key / Secret Key 和本机路径。分享前请删除或脱敏同步配置。

### Q47. 有遥测吗？

没有账号系统，也没有统计上报。网络只用于远端同步、Lakebook 图片下载和打开外部链接。

### Q48. 支持深色模式吗？

当前界面为浅色主题，没有深色模式或主题切换设置。

### Q49. 支持手机/平板吗？

不支持。语燕是桌面应用；没有 iOS/Android 客户端。

### Q50. 支持多人协作吗？

不支持实时协作、评论、权限或冲突合并。可以通过共享文件夹或版本控制工具自行协作，但语燕本身不处理多人并发。

## 9. 仍然无法解决

请按以下步骤反馈：

1. 打开设置 > 诊断日志，导出最近 3 天日志 ZIP；
2. 记录语燕版本、操作系统和复现步骤；
3. 说明是否使用了同步、外部知识库、Lakebook 导入；
4. 在项目仓库提交 Issue：<https://github.com/JHJMK/swift/issues>。

> **注意**：日志可能包含文件路径和文件名。发送前请自行检查 ZIP 内容；不要附带包含 S3 密钥的配置文件。
