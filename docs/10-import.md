# 导入

[返回教程目录](README.md) · [返回项目主页](../README.md)

语燕支持四类导入：

| 导入方式 | 来源 | 结果 |
| --- | --- | --- |
| 复制导入知识库 | 一个包含 Markdown 的文件夹 | 在文档目录中创建一个新的本地知识库，内容被复制 |
| 引用外部知识库 | 文档目录之外的文件夹 | 在侧栏中增加一个外部知识库引用，不复制文件，直接读写原文件夹 |
| 导入 Lakebook | `.lakebook` 归档 | 创建一个新的本地知识库，目录、文档和图片被转换 |
| 导入文档 | 单个 Markdown、TXT 或 DOCX 文件 | 在当前知识库、目录或文档下创建一篇文档 |

## 1. 导入入口

### 1.1 知识库相关导入

- 左侧「知识库」右侧 `+` > 「导入」；
- 工作台「导入知识库」卡片；
- 菜单栏 文件 > 复制导入知识库… / 引用外部知识库…。

展开后有三项：

- **复制导入知识库**
- **引用外部知识库**
- **导入 Lakebook**

> **提示**：菜单栏「文件」只提供复制导入和引用外部，没有 Lakebook 和单文档导入；Lakebook 请用侧栏或工作台入口。

### 1.2 单篇文档导入

单篇文档导入位于当前知识库或目录内部：

- 知识库标题右侧 `+` > 「导入」；
- 目录树某一行 `+` > 「导入」；
- 目标可以是知识库、目录或文档。选择文档时，导入的文档会成为它的子文档。

## 2. 复制导入知识库

适合把已有的 Markdown 文件夹完整搬进语燕。

### 2.1 步骤

1. 点击 `+` > 「导入」> 「复制导入知识库」；
2. 选择源文件夹；
3. 语燕以源文件夹的名称创建新知识库；
4. 递归读取源文件夹中的 Markdown 文件，保持目录结构；
5. 复制文档引用的本地图片和附件到目标知识库的 `.assets/`；
6. 导入完成后打开新知识库。

### 2.2 处理规则

- **支持的文档**：`.md`、`.markdown`。其他文件不会作为文档导入。
- **目录结构**：源文件夹的子目录会变成知识库中的目录；文档与其同名子目录的关系也会保留。
- **图片和附件**：只复制被 Markdown 实际引用的本地文件；远程 URL 保持原样；找不到的文件保留原引用，不会中断导入。
- **链接重写**：指向本地图片和附件的相对路径、绝对路径会被改写为 `.assets/` 中的新路径；指向其他 `.md` 的链接保持原样。
- **隐藏文件**：以 `.` 开头的目录和文件会被跳过，例如 `.git/`、`.DS_Store`。
- **不移动源文件**：导入是复制，原文件夹保持不变。
- **名称冲突**：新知识库名称如果已存在，会自动加编号。
- **层级**：语燕的目录树最多显示 4 级；如果源目录更深，内容仍在磁盘上，但树的更深层不会显示。建议导入后整理到 4 级以内。

### 2.3 适合的场景

- 从其他 Markdown 工具迁移整个笔记库；
- 把同事分享的 Markdown 文件夹收进自己的知识库；
- 把项目文档、会议记录等一次性归档。

## 3. 引用外部知识库

适合继续在原工具中维护、并让语燕和原工具共用同一批文件的文件夹。

### 3.1 步骤

1. 点击 `+` > 「导入」> 「引用外部知识库」；
2. 选择文件夹；
3. 语燕在侧栏加入一个同名知识库，并记住路径；
4. 点击即可浏览和编辑；保存会直接写回原文件夹。

### 3.2 规则

- 文件夹不会被复制或移动；
- 文档状态显示「· 外部引用」，但**不是只读**；编辑、重命名和删除会作用在原文件夹；
- 删除外部文档/子目录会移入语燕回收站，原文件夹中的文件会消失，请谨慎操作；
- 外部知识库参与搜索，但不参与远端同步；
- 可以导出整个知识库；
- 可以「移除外部知识库」，只移除引用，不删除原文件；
- 不能引用文档目录内部的文件夹（会提示该文件夹已在文档目录内）；
- 同名引用会自动编号；
- 如果原文件夹被移动、删除或磁盘未挂载，重启后不会出现在列表中，恢复后重新引用即可。

外部知识库的完整说明见[知识库管理](03-knowledge-bases.md#7-外部知识库引用已有文件夹)。

## 4. 导入 Lakebook

Lakebook 是一种包含知识库目录、文档 JSON 和 HTML 正文的 tar 归档格式。语燕可以把它转换成一份本地的 Markdown 知识库。

### 4.1 准备

1. 准备一个 `.lakebook` 归档文件；
2. 确认文件完整，且没有超过大小限制；
3. 在语燕中点击 `+` > 「导入」> 「导入 Lakebook」；
4. 选择文件。

导入在后台准备：解析归档、转换正文、下载图片。准备完成后，语燕会创建知识库并打开它。侧栏会显示导入进度。

### 4.2 会导入什么

| Lakebook 内容 | 语燕中的结果 |
| --- | --- |
| 知识库目录（TITLE） | 目录 / 分组 |
| 文档（DOC） | Markdown 文档 |
| 文档层级 | 保持原来的父子关系 |
| 画板（BOARD） | 一篇静态文档，保留标题、文字、预览图和原链接，并注明暂不支持交互编辑 |
| 正文 | 转换为 Markdown，支持标题、段落、列表、代码块、表格、链接、图片、引用、分割线等常见结构 |
| 图片 | 下载到新知识库的 `.assets/` |

### 4.3 图片下载

- 只下载 `http://` 和 `https://` 图片；
- 单张图片超过 20MB 会跳过；
- 单次导入的图片总量上限约 200MB；
- 请求超时 15 秒；
- 某张图片失败不会中断导入，正文中会保留原远程 URL；
- 导入结束后提示本次成功和失败的图片数量；
- 失败的图片如果原链接仍可访问，打开文档时可能显示；否则会显示缺失。

### 4.4 画板

Lakebook 画板不能转换为可交互的绘图。导入后会变成一篇普通文档，内容通常包括：

- 画板标题；
- 可见文字；
- 预览图（如果有）；
- 原链接；
- 一句说明：「此内容来自 Lakebook 画板，暂不支持交互编辑。」

这不是完整恢复，但能保留可读信息，不会静默丢弃。

### 4.5 限制

- 只支持 Lakebook 归档，不兼容其他导出格式；
- 不导入评论、历史版本、权限、协作状态等应用元数据；
- 不支持交互式画板；
- 导入层级最多 4 级；超过会拒绝整个归档；
- 归档大小上限 32MB（压缩后）、解压后上限 256MB、最多 2000 个条目；
- 同一时间只能运行一个 Lakebook 导入；
- 无效归档会在创建知识库之前失败，不会留下半成品知识库；
- 导入完成后不会保留 Lakebook 原文件，源 `.lakebook` 文件仍在原位置。

> **注意**：Lakebook 导入会从归档中的图片地址发起网络请求。请在可信网络中使用，并确认归档来源可信。

## 5. 导入单篇文档

### 5.1 步骤

1. 在目录树中选中目标知识库、目录或文档；
2. 点击行尾 `+` > 「导入」，或知识库标题 `+` > 「导入」；
3. 选择文件；
4. 语燕创建同名文档，转换内容，复制图片，并打开它。

一次只能导入一个文件。批量导入请使用「复制导入知识库」。

### 5.2 支持格式

| 扩展名 | 支持情况 | 说明 |
| --- | --- | --- |
| `.md`、`.markdown`、`.mdown` | 支持 | 保留 Markdown；本地图片和附件复制到 `.assets/` |
| `.txt` | 支持 | UTF-8（含 BOM）或 GB18030 编码；保留原有换行；Markdown 语法按普通文字处理 |
| `.docx` | 支持 | 转换标题、段落、列表、表格、图片和常见行内格式 |
| `.doc` | 不支持 | 请先用 Word/WPS 另存为 `.docx` |
| `.pdf` | 不支持 | 不能作为可编辑文档导入 |
| 其他 | 不支持 | 会提示不支持的格式 |

### 5.3 Markdown 文件

- 文档标题取自文件名（去掉扩展名）；
- 正文中的本地图片、附件引用会被复制并重写；
- 网络图片保持原 URL；
- 指向其他 `.md` 的链接保持原样；
- 源文件不会被移动；
- 如果同名文档已存在，新文档会自动加编号。

### 5.4 TXT 文件

- 优先按 UTF-8 解码；不是合法 UTF-8 时尝试 GB18030；
- 保留原始物理换行和空行；
- TXT 中的 `#`、`*`、`-`、`1.` 等 Markdown 标记会被转义，避免被误当成格式；
- 不解析图片或附件；
- 适合导入日志、旧笔记、纯文本资料。

### 5.5 Word（.docx）

语燕会转换：

- 标题样式（Heading 1–9 映射为 Markdown 标题，最多 6 级）；
- 普通段落；
- 无序列表、有序列表、嵌套层级；
- 粗体、斜体、删除线、下划线；
- 表格（转为 Markdown 管道表格）；
- 文档内嵌图片（复制到 `.assets/`）；
- 手动换行。

可能无法完整保留：

- 页眉、页脚、页码、目录；
- 文本框、艺术字、SmartArt、图表；
- 批注、修订记录；
- 复杂分栏、页面边框；
- 部分超链接样式；
- 特殊字体和精确间距。

需要高保真时，请保留原 Word 文件；语燕的转换目标是把内容变成可编辑的 Markdown。

## 6. 从其他工具迁移

### 6.1 从其他 Markdown 工具

1. 关闭原编辑器，或至少停止写入；
2. 在语燕中「复制导入知识库」，选择整个笔记文件夹；
3. 以 `.` 开头的隐藏目录和文件会被跳过；
4. 本地图片和附件会被复制到 `.assets/`；
5. `[[双链]]` 会保留为文本/链接样式，但不提供反向链接和图谱；
6. 原工具的提示块、数据库视图、白板等扩展功能不会渲染。

如果只想在原位置查看、编辑而不复制，可以用「引用外部知识库」；注意这会直接读写原文件夹。

### 6.2 从 Lakebook 归档

- 用「导入 Lakebook」，选择 `.lakebook` 文件；
- 只支持 Lakebook 归档，不兼容其他导出格式；
- 画板只能静态保留。

### 6.3 从 Word

- 单篇 `.docx` 用「导入文档」；
- 多篇 Word 文档建议先转成 Markdown 或逐篇导入；
- `.doc` 请先另存为 `.docx`。

### 6.4 从其他笔记工具

通常可以导出为 Markdown + 附件的 ZIP。解压后：

- 如果得到的是文件夹，用「复制导入知识库」；
- 如果只有单篇 Markdown，用「导入文档」；
- 导出格式不是 Markdown 时，先转换成 Markdown 或复制正文。

## 7. 常见问题

**Q：导入后图片不显示？**

检查图片是否在源文件夹内、引用是否是相对路径、文件是否真的存在。远程图片需要联网；绝对路径可能无法复制。导入失败不会中断，但会保留原引用。

**Q：导入的 TXT 乱码？**

文件可能不是 UTF-8 或 GB18030 编码。用文本编辑器另存为 UTF-8 后重新导入。

**Q：为什么 .doc 不能导入？**

旧版二进制 Word 格式解析复杂且容易失真。请另存为 `.docx`。

**Q：Lakebook 导入到一半失败？**

如果归档解析失败，语燕不会创建知识库；如果已经创建后写入失败，可能留下部分内容。查看错误提示和日志，修复后重新导入。图片下载失败不会导致整体失败。

**Q：Lakebook 的图片没下载下来？**

检查网络、图片链接是否失效、是否超过大小限制。失败图片会保留原 URL，成功数量会在导入完成的提示中显示。

**Q：导入后目录超过 4 级？**

磁盘上的文件可能还在，但树不会显示更深层。请把内容整理到 4 级以内，或拆分成多个知识库。

**Q：外部知识库能编辑吗？**

能。外部知识库是活引用，编辑、重命名、删除会直接作用在原文件夹。若只想查看或需要一份独立副本，请使用「复制导入知识库」。

**Q：导入会修改原文件吗？**

复制导入、单文档导入和 Lakebook 导入都读取源文件并写入新位置，不修改源文件；外部引用则会直接读写原文件夹。
